## YouTube Super Comments - ChangeLog

### v1.6.2 — 2026-09-18
- Validação estrita de tokens (tokenBelongsToVideo): descarta tokens obsoletos de ytInitialData em navegações SPA
- Consulta automática do watch data atualizado da API para novos vídeos
- Remoção do delay inicial de 800ms em initForVideo (inicialização imediata e retentativas a cada 100ms)
- Limpeza imediata de todos os cards de comentários residuais na navegação
- Intervalos de paginação e debounce reduzidos para exibição ultrarrápida

### v1.6.1 — 2026-09-18
- Correção de TypeError: Failed to fetch (caminho relativo /youtubei/v1/next, credentials same-origin e bound fetch)

### v1.6.0 — 2026-09-18
- Busca proativa via InnerTube API totalmente resiliente a navegação SPA (sem recarregar página)
- Fallback automático para consulta de watch data via API (/youtubei/v1/next com videoId) quando ytInitialData estiver desatualizado
- Extração ultra-robusta de tokens de comentários (suporte a layouts engagementPanels, itemSectionRenderer e busca recursiva inteligente)
- Handshake bidirecional de mensagens entre injected.js e content.js (cache de comentários por vídeo, sem perda de mensagens de boot)
- Interceptação de tokens em respostas nativas de watch-next do YouTube
- Suporte a timestamps com início em 0:00 e segundos >= 0

### v1.5.0 — 2026-09-18
- Limpeza e rejeição estrita de comentários do vídeo anterior na troca de página/SPA
- Botão fechar (✕) reposicionado para o canto superior direito do card, visível em hover
- Correção dos avisos de line-clamp e -webkit-line-clamp no CSS

### v1.4.0 — 2026-09-18
- Expansão de comentários com clique no card no player
- Pausa automática do temporizador do card ao passar o mouse
- Exibição em pilha vertical para múltiplos comentários simultâneos
- Correção de duplicação de cards ao navegar via popup

### v1.3.0 — 2026-09-18
- Corrigido bug de fetch duplicado: debounce + rastreamento por video ID evitam chamadas duplas à API
- Limite de páginas aumentado de 10 para 50 (~1000 comentários por vídeo)
- Redesign completo do popup e overlay: paleta Indigo/Violeta (#7c5cff) mais profissional
- Tipografia atualizada para fonte Inter (Google Fonts)
- Fundo navy escuro (#0c0c14) com superfícies em camadas para melhor hierarquia visual
- Badges de timestamp redesenhados: pills violeta suaves com borda translúcida
- Animação de hover nos cards do popup com deslocamento lateral suave

### v1.2.0 — 2026-09-18
- Substituição completa do DOM scraping por chamada direta à InnerTube API (/youtubei/v1/next)
- Criado injected.js (world: MAIN) para acesso ao contexto da página (window.ytInitialData, fetch, XHR)
- Extração robusta do token de comentários com 3 caminhos de busca em ytInitialData
- Loop de polling (até 10s) para aguardar ytInitialData estar disponível
- Interceptação passiva de fetch e XHR para capturar comentários carregados organicamente
- Uso de _origFetch para chamadas proativas (evita loop infinito no interceptor)
- Logs detalhados no console (prefixo [YTSuperComments]) para diagnóstico
- content.js simplificado: removido DOM scanner, adicionado listener de postMessage

### v1.1.0 — 2026-09-18
- Arquitetura refatorada: injected.js (world: MAIN) + content.js (world: ISOLATED)
- manifest.json atualizado para Manifest V3 com dois content scripts
- Comunicação entre mundos via window.postMessage

### v1.0.0 — 2026-09-18
- Versão inicial da extensão
- Detecção automática de comentários com timestamps no DOM do YouTube
- Overlay dentro do player com glassmorphism, animação pop-in elástico e fade-out suave
- Suporte a formatos M:SS, MM:SS e H:MM:SS
- Sincronização em tempo real com currentTime do vídeo
- Popup com lista de timestamps clicáveis e toggle de ativação
- Seletor de duração de exibição dos cards (4s - 20s)
- Compatibilidade com SPA navigation do YouTube
- Suporte a tela cheia, modo teatro e modo normal
- Barra de progresso visual em cada card de comentário
- MutationObserver para detecção em tempo real conforme comentários carregam
